# NEET PCB 30-Day Tracker

A mobile-friendly 30-day Physics, Chemistry and Biology question-practice tracker.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload **index.html** and **manifest.json** (and this README if you want).
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then Save.
6. Open the GitHub Pages URL after deployment.

The tracker stores progress in the browser using localStorage, so progress is saved on that device/browser.
