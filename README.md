# NEET PCB 120-Day Tracker

A mobile-friendly 120-day Physics, Chemistry and Biology question-practice tracker covering **3 September 2026 through 31 December 2026**.

## Features
- 120 daily tracks
- Fixed dates from 3 Sep to 31 Dec 2026
- Enter any number of questions; 50+ turns a subject green
- +10, -10 and +50 quick buttons
- Daily total = Physics + Chemistry + Biology
- Today's track opens automatically; other days can be expanded/collapsed
- Overall, subject-wise and daily progress
- Progress saved in the browser with localStorage
- Installable as a PWA when supported by the browser

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and `manifest.json` (README optional).
3. Go to **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select your `main` branch and `/ (root)`, then Save.
6. Open the GitHub Pages URL after deployment.

The tracker stores progress on the device/browser. Clearing browser site data can remove saved progress.
